# 15: Criar Grupo

**Tipo:** Implementação
**Página:** Criação de Grupo

## Descrição

Admin ou Gerente preenche o formulário (nome obrigatório, time opcional, membros e participantes opcionais) e clica em "Criar grupo"; o grupo é criado via API Oficial, membros selecionados são adicionados automaticamente e o usuário é redirecionado para o Detalhe do Grupo; sistema exibe erro se a API falhar ou se o nome estiver vazio.
