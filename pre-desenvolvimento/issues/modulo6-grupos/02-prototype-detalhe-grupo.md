# 02: Protótipo — Detalhe do Grupo

**Tipo:** Protótipo
**Página:** Detalhe do Grupo

## Descrição

Criar a UI estática da página de detalhe do grupo com área de histórico de mensagens, campo de composição com anexos, e painel lateral com nome (editável), time associado, lista de participantes do workspace, lista de membros WhatsApp e botões de gerenciamento.
