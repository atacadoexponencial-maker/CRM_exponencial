# 15: Reenviar para os que Falharam

**Tipo:** Implementação
**Página:** Relatório de Campanha

## Descrição

Usuário clica em "Reenviar para os que falharam" — o Editor de Campanha abre pré-preenchido com os mesmos dados da campanha original e a lista de destinatários filtrada apenas para os contatos com falha.
