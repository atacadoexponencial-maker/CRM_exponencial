# 02: Protótipo — Editor de Campanha

**Tipo:** Protótipo
**Página:** Editor de Campanha

## Descrição

Criar a UI estática do editor de campanha em três etapas: (1) Destinatários com filtros de segmentação e preview da contagem; (2) Mensagem com seletor de tipo, campo de texto com variáveis e preview renderizado; (3) Agendamento com opção imediato/agendado, resumo e botões de confirmar/rascunho.
