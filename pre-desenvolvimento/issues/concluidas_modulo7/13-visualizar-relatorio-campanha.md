# 13: Visualizar Relatório de Campanha

**Tipo:** Implementação
**Página:** Relatório de Campanha

## Descrição

Admin ou Gerente acessa o relatório de uma campanha enviada e visualiza cards de resumo (total enviado, entregues, lidos, falhos), taxas de entrega e leitura, e lista detalhada de destinatários com status individual atualizado em tempo real via webhook da API Oficial.
