# 10: Enviar Campanha Imediatamente

**Tipo:** Implementação
**Página:** Editor de Campanha — Etapa 3

## Descrição

Usuário escolhe "Enviar imediatamente" e confirma; o sistema inicia o envio individualmente para cada destinatário via WhatsApp API, o status muda para "Enviando" e ao término para "Enviada".
