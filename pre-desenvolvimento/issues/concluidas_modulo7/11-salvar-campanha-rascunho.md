# 11: Salvar Campanha como Rascunho

**Tipo:** Implementação
**Página:** Editor de Campanha

## Descrição

Usuário clica em "Salvar como rascunho" em qualquer etapa do editor; a campanha é salva com status "Rascunho" e aparece na lista de campanhas, preservando todos os dados preenchidos até aquele momento.
