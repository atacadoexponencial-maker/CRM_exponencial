# 09: Agendar Campanha

**Tipo:** Implementação
**Página:** Editor de Campanha — Etapa 3

## Descrição

Usuário escolhe "Agendar para data e hora específicas", preenche a data e hora, seleciona o número de WhatsApp de envio (quando há mais de um) e confirma; o status muda para "Agendada" e o envio é disparado automaticamente na data/hora configurada.
