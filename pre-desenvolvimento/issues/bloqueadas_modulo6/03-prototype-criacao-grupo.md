# 03: Protótipo — Criação de Grupo

**Tipo:** Protótipo
**Página:** Criação de Grupo

## Descrição

Criar a UI estática do formulário de criação de grupo com campo de nome, seletor de time associado, busca e seleção de contatos como membros iniciais, seleção de atendentes como participantes gestores e botões "Criar grupo" e "Cancelar".
