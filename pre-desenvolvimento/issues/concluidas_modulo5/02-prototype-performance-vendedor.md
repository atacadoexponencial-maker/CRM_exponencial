# 02: Protótipo — Performance por Vendedor

**Tipo:** Protótipo
**Página:** Performance por Vendedor

## Descrição

Criar a UI estática da página de performance com seletor de período, tabela de atendentes com colunas de métricas individuais (leads, conversões, taxa, clientes ativos, em risco, recompras, ticket médio) e painel expansível de detalhe por atendente.
