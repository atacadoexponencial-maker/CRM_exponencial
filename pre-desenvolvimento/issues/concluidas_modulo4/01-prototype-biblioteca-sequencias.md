# 01: Protótipo — Biblioteca de Sequências

**Tipo:** Protótipo
**Página:** Biblioteca de Sequências

## Descrição

Criar a UI estática da página de listagem de sequências com lista de sequências (nome, tipo, status, contagem), badge diferenciando pré-definidas de personalizadas, toggle de ativar/desativar e botão "Nova sequência".
