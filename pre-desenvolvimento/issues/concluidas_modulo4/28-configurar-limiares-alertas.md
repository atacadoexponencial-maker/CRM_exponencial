# 28: Configurar Limiares de Alertas

**Tipo:** Implementação
**Página:** Central de Alertas

## Descrição

Admin altera o número de dias sem atividade de qualquer tipo de alerta (lead sem resposta, cliente sem recompra, cliente em risco, cliente inativo) e o novo limiar é aplicado imediatamente para recalcular os alertas ativos.
