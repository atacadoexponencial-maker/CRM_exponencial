# 16: Iniciar Sequência Manualmente

**Tipo:** Implementação
**Página:** Ativação de Sequência

## Descrição

Atendente, Gerente ou Admin clica em "Iniciar sequência" no Perfil do Contato ou Painel do Card, seleciona uma sequência ativa no modal e o sistema agenda a primeira etapa conforme o prazo configurado; sistema rejeita iniciar a mesma sequência duas vezes enquanto há execução em andamento.
