# 02: Protótipo — Editor de Sequência

**Tipo:** Protótipo
**Página:** Editor de Sequência

## Descrição

Criar a UI estática do formulário de criação e edição de sequência, com campo de nome, seletor de gatilho, lista de etapas com drag-and-drop, botão "Adicionar etapa" e formulário de etapa (modal/painel lateral) com tipo, prazo e conteúdo.
